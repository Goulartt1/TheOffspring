# The Offspring - Site Tributo

Site tributo à banda The Offspring, desenvolvido como projeto de estudo de frontend. O objetivo foi praticar conceitos de HTML e CSS partindo dos fundamentos mais básicos em direção a conceitos mais avançados, simulando um fluxo real de desenvolvimento de software.

## Acesse o site

[https://goulartt1.github.io/TheOffspring](https://goulartt1.github.io/TheOffspring)

## Objetivo

Praticar o desenvolvimento frontend de forma incremental, passando por:

- Levantamento e documentação de requisitos
- Estrutura semântica com HTML5
- Estilização moderna com CSS (variáveis, Flexbox, Grid)
- Responsividade com media queries
- Suporte a dark/light mode
- Versionamento com Git e Conventional Commits
- Deploy com GitHub Pages

## Tecnologias

- HTML5
- CSS3
- Google Fonts
- Spotify Embed
- GitHub Pages

## Estrutura da página

| Seção | Descrição |
|---|---|
| Navbar | Menu fixo com links de navegação para cada seção |
| Hero | Imagem de fundo com nome da banda e botão de ação |
| História | Texto sobre a trajetória da banda com imagem lateral |
| Integrantes | Cards com foto, nome e função de cada membro |
| Discografia | Grid com capas dos 10 álbuns de estúdio |
| Galeria | Mosaico de fotos da banda ao vivo |
| Player | Embed do Spotify com a discografia completa |
| Curiosidades | Cards com fatos marcantes sobre a banda |
| Redes Sociais | Botões com links para as redes oficiais |
| Footer | Copyright e créditos |
